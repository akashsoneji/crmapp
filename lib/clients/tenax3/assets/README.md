This folder exists for `tenax3` client structure consistency.

`tenax3` currently reuses Tenax assets (icons/logos/splash) from:
- `lib/clients/tenax/assets/`
- runtime paths via `assets/clients/tenax/...`

If you later want Tenax3-specific branding, place the assets here and switch
the asset paths in `lib/flavor_config.dart` to `assets/clients/tenax3/...`.
