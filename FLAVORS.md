## Adding a New Flavor

To add a new flavor (e.g., `newname`), you need to modify/create the following files:

### 1. `lib/clients/newname/config.dart`
Create the client configuration class:
```dart
import 'package:flutter/material.dart';
import '../base_config.dart';

class NewnameConfig extends BaseClientConfig {
  const NewnameConfig()
    : super(
        brandName: 'NewName',
        appTitle: 'NewName',
        primaryColor: const Color(0xFFXXXXXX),
        secondaryColor: const Color(0xFFXXXXXX),
        accentColor: const Color(0xFFXXXXXX),
        logoSvgPath: 'logo.svg',
        splashLogoPath: 'splash_logo.svg',
        appIconPath: 'app_icon.png',
        apiBaseUrl: 'https://api.newname.com/api/',
        websocketUrl: 'wss://api.newname.com/trade-engine',
        chartBaseUrl: 'https://api.newname.com',
      );
}
```

### 2. `lib/clients/newname/launcher_icons.yaml`
Create launcher icon configuration:
```yaml
flutter_launcher_icons:
  android: true
  ios: false
  image_path: 'assets/app_icon.png'
  adaptive_icon_background: '#XXXXXX'
  adaptive_icon_foreground: 'assets/app_icon.png'
```

### 3. `lib/clients/newname/assets/` folder
Add the following assets:
- `logo.svg` - App logo SVG
- `splash_logo.svg` - Splash screen logo SVG
- `app_icon.png` - App icon (1024x1024 recommended)

### 4. `android/app/build.gradle.kts`
Add the product flavor:
```kotlin
create("newname") {
    dimension = "brand"
    applicationId = "com.example.newname"
    resValue("string", "app_name", "NewName")
    resValue("color", "primary_color", "#XXXXXX")
    resValue("color", "secondary_color", "#XXXXXX")
    resValue("color", "accent_color", "#XXXXXX")
    buildConfigField("String", "FLAVOR", "\"newname\"")
    manifestPlaceholders["FLAVOR"] = "newname"
}
```

### 5. `android/app/src/newname/` folder structure
Create the following files:
- `AndroidManifest.xml` - (copy from another flavor, update package name if needed)
- `google-services.json` - Firebase configuration (get from Firebase Console)
- `res/values/colors.xml` - Splash and theme colors
- `res/drawable/launch_background.xml` - Launch screen background
- `res/drawable-v21/launch_background.xml` - Launch screen background (v21+)

### 6. `scripts/prepare_flavor.dart`
Add `'newname'` to the `allFlavors` list(s) - there are 2 places where this needs to be added.

### 7. `build.sh`
- Add `newname` to the flavor list in the usage message
- Add `newname` to the `CLIENTS` array

## Build Commands

### Single Flavor
```bash
./build.sh newname apk release
./build.sh newname appbundle release
```

### All Flavors
```bash
./build.sh all apk release
./build.sh all appbundle release
```

### With Universal APK (single APK for all architectures)
```bash
./build.sh newname apk release universal
```

### Debug Mode
```bash
./build.sh newname apk debug
```

## Flavor Configuration Files

### Android Source (`android/app/src/{flavor}/`)
```
{flavor}/
├── AndroidManifest.xml
├── google-services.json
└── res/
    ├── drawable/
    │   └── launch_background.xml
    ├── drawable-v21/
    │   └── launch_background.xml
    └── values/
        └── colors.xml
```

### Dart Configuration (`lib/clients/{flavor}/`)
```
{flavor}/
├── config.dart
├── launcher_icons.yaml
└── assets/
    ├── logo.svg
    ├── splash_logo.svg
    └── app_icon.png
```

## Notes

- The `prepare_flavor.dart` script handles:
  - Cleaning other client assets
  - Copying client assets to `assets/clients/{flavor}/`
  - Updating `pubspec.yaml`
  - Generating native splash resources
  - Generating launcher icons

- Icons in `android/app/src/{flavor}/res/mipmap-*/` are auto-generated by `flutter_launcher_icons` during the build preparation step.

- Each flavor needs its own `google-services.json` from the Firebase Console for push notifications to work.

- The `FLAVOR` build config field is used throughout the app to identify which flavor is being built.
